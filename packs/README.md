# Domain packs

Each directory here is one domain pack following the layout in DESIGN.md section 5. Packs are
kept in this repository until phase 9, when `support-core` and the sample pack split into
separately distributable packages (BACKLOG.md decisions log).

- `acme_billing/`: the sample pack used by the tests and the worked example in DESIGN.md section 19.

Validate a pack with `support pack validate packs/acme_billing`.
